# Questions

## Q1

### Why was cloud computing invented?

### My Answer

Cloud computing was invented to reduce costs, provide services on demand, and allow companies to focus more on innovation rather than spending time and money maintaining hardware and infrastructure.

### Mentor Feedback

Correct.

Cloud computing also helps solve problems such as slow deployment, difficult scaling, and managing physical data centers.

---

## Q2

### What problem does cloud computing solve?

### My Answer

Cloud computing solves the problems of infrastructure maintenance, high hardware costs, elasticity, and scaling.

### Mentor Feedback

Correct.

It also allows businesses to provision resources quickly and pay only for what they use.

## Q3

### What is a network?

### My Answer

A network is a group of connected devices that communicate and share information with each other.

### Mentor Feedback

Correct.

Networking is the technology that allows this communication.

## Q4

### What is a client?

### My Answer

A client is a device or application that requests services or resources from a server.

Examples:

- Laptop
- Mobile phone
- Browser
- Mobile application

### Mentor Feedback

Correct.

Remember that a client is not always a person.

---

## Q5

### What is a server?

### My Answer

A server is a computer or software that provides services, data, or resources to clients.

A server can be:

- Physical
- Virtual
- Cloud-based

### Mentor Feedback

Originally I thought every server was virtual.

Now I understand that servers existed long before virtualization.

## Q6

### Explain the client-server model using YouTube.

### My Answer

Client:
The YouTube app or browser on my device.

Server:
YouTube's servers.

Request:
Request for a video.

Response:
The requested video is sent back to my device.

### Mentor Feedback

Correct.

The user operates the client, but the browser or app is the actual client in networking.

---

## Q7

### If AWS disappeared tomorrow, what problems would companies face?

### My Answer

- Applications may stop working.
- Services could crash under high traffic.
- Companies would have to purchase expensive hardware.
- They would need to build and maintain their own data centers.
- Infrastructure costs would increase.
- Less time would be available for innovation because more effort would go into infrastructure management.

### Mentor Feedback

Excellent reasoning.

Large companies could migrate elsewhere, but doing so would require significant time, money, and engineering effort.
