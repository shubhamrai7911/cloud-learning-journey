# Mistakes

## Mistake 1

### I thought

Every server is virtual.

### Mentor explained

Servers can be physical or virtual.

Cloud servers are usually virtual machines running on physical servers.

### My final understanding

A server is simply a computer that provides services.

It doesn't matter whether it is physical or virtual.

---

## Mistake 2

### I thought

Phone + Zomato server itself is the network.

### Mentor explained

The phone and server are devices.

The Internet/Wi-Fi is the communication path between them.

### My final understanding

The network carries the request between client and server.
