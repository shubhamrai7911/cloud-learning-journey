## Why Cloud Computing?

Before cloud computing, companies had to:

- Buy servers
- Build data centers
- Maintain infrastructure
- Estimate future demand
- Spend huge amounts of money before launching

Cloud computing allows companies to rent computing resources instead.

---

## Network

A network is a group of connected devices that communicate and exchange information.

Example:

- Laptop
- Mobile
- Printer

Connected through Wi-Fi.

---

## Client

A client is a device or application that requests a service.

Examples:

- Chrome Browser
- YouTube App
- Instagram App

---

## Server

A server is a computer that provides services or resources to clients.

Examples:

- YouTube Server
- Instagram Server
- Google Server
