# Question 1

## Why was cloud computing invented?

### My Answer

Companies had to buy servers, build data centers, spend huge amounts of money, maintain infrastructure, and estimate future traffic before even launching their applications.

### Mentor's Feedback

✅ Good understanding.

You correctly identified the major business problems.

To make your answer stronger, explain that cloud computing allows companies to rent IT resources over the internet instead of owning and maintaining infrastructure.

### Final Understanding

Cloud computing was invented because building and maintaining infrastructure was expensive, slow, and difficult to scale. Cloud providers allow companies to rent IT resources over the internet instead of buying and maintaining everything themselves.

- YouTube Server
- Instagram Server
- Google Server

### Mentor's Feedback

# Question 5

## Explain the client-server model.

### My Answer

The client sends a request through the network.

The server receives it, processes it, and sends a response back.

Example:

User

↓

Browser

↓

Internet

↓

YouTube Server

↓

Video

↓

Browser

### Mentor's Feedback

✅ Excellent.

You understood the complete request-response cycle.

### Final Understanding

The client-server model is a communication model where the client sends a request, the network carries it to the server, the server processes it, and the response is returned to the client.

# Question 6

## What happens if the Internet stops working?

### My Answer

The client and server would still exist, but they could no longer communicate because the network connection had failed.

### Mentor's Feedback

✅ Excellent reasoning.

The client and server do not disappear; only the communication between them stops.

### Final Understanding

Without a working network, requests cannot reach the server and responses cannot return to the client, even though both systems still exist.
